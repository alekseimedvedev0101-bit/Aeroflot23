# Live Financial Dashboard (Excel-backed, localhost)

A recipe for a small, local dashboard that reads an Excel workbook, serves
its figures over a read-only localhost API, and renders them in a browser.
Every number on screen must trace back to a specific sheet and cell in the
workbook. Nothing final is computed or cached in the HTML.

## 0. Ground rules

- **Stay inside the project workspace.** Read, write, create and delete
  only under the project root. No writes to `$HOME`, `/tmp` or system
  directories. Temporary workbook copies go in `<project>/.cache/`, which is
  git-ignored. Never follow a configured path that resolves outside the
  root: resolve it, check it, and refuse if it escapes.
- **Never modify the source workbook.** Open it read-only and parse a
  snapshot.
- **Deterministic.** The same workbook bytes always produce byte-identical
  JSON: sorted keys, stable ordering of periods and segments, no
  timestamps inside the computed payload (put load metadata in a separate
  `meta` block), and `Decimal` or round-half-even rounding applied only at
  the presentation boundary.
- **No network at runtime.** No CDN, fonts, analytics or telemetry.
  Everything the page loads comes from `web/`.
- Follow any project rules (`CLAUDE.md`, `AGENTS.md`, `.claude/rules/`)
  where they exist. They take precedence over this skill.

## 2. Parser (`parser.py`)

- Use `openpyxl.load_workbook(path, read_only=True, data_only=True)`.
  `data_only=True` reads the values Excel last calculated. If a formula
  cell has no cached value (`None` where a formula exists), report a
  `formula_not_calculated` warning. Do not evaluate the formula yourself.
- Drive parsing from a declarative **sheet map** in `config.py`: KPI id →
  sheet, label cell or row header, period header row, unit, and sign
  convention. Locate rows by header text, not by hard-coded row numbers,
  so inserting rows in Excel doesn't break the parse. Fail loudly with a
  warning if a header can't be found.
- Produce a canonical model:

  ```python
  Fact(kpi="revenue", period="2025-Q3", segment="Passenger", value=Decimal("123456.7"),
       unit="RUB mn", source=SourceRef(sheet="P&L", cell="F14", header="Выручка",
                                        period_header="3 кв. 2025", raw="123456,7"))
  ```

- **Periods.** Normalise to ISO-like keys: `2025`, `2025-H1`, `2025-Q3`,
  `2025-09`. Keep the original header text in `source.period_header`.
  Accept Excel date serials, `datetime`, and text such as
  `"3 кв. 2025"`, `"Q3 2025"`, `"9М 2025"` and `"сен.25"`. Mark
  cumulative periods (9M, H1 YTD) with `is_cumulative=True` so they are
  never summed with discrete quarters.
- **Units.** Each KPI has an explicit unit (`RUB mn`, `RUB bn`, `%`,
  `pax thousand`, `ASK mn`, …). Parse a unit row or note on the sheet when
  one exists, and add a `unit_mismatch` warning if it contradicts the
  config. Never silently rescale.
- **Numbers.** Accept numeric cells. For text cells, accept Russian
  formatting (non-breaking or thin space as the thousands separator, comma
  as the decimal mark, `(123)` or a Unicode minus for negatives). Anything
  else becomes `None` plus a `non_numeric_value` warning that carries the
  cell ref.
- **Segments.** Only segments listed in `config.SEGMENTS` are supported
  lenses (for example `Total`, plus the business or geographic segments
  present in the workbook). An unknown segment found in the workbook
  produces an `unknown_segment` warning and is excluded from lenses.
  `Total` is taken from the workbook, not recomputed. The sum-of-segments
  check lives in `quality.py`.
- The parser is pure: given a file path, it returns
  `(facts, warnings, workbook_meta)`. No globals and no I/O beyond reading
  that one file.

## 3. Metrics (`metrics.py`)

- **Lens** = `(year | period, segment)`. Filtering is pure and returns
  facts plus their source refs.
- **YoY**: `(curr − prior) / |prior|` for the same period type one year
  earlier (Q3-2025 vs Q3-2024, 9M vs 9M). When the prior value is missing
  or zero, return `None` with a reason and add a `yoy_unavailable`
  warning. For `%` KPIs, show the change in **percentage points (п.п.)**,
  not a relative %.
- **LTM** (last twelve months): the sum of the last 4 discrete quarters,
  or `FY(prev) + YTD(curr) − YTD(prev)` when only cumulative data exists.
  Flow KPIs only. Stock or balance KPIs use the period-end value, and
  ratios are recomputed from LTM components, never summed. If any
  component is missing, LTM is `None` with an `ltm_incomplete` warning
  listing the missing periods.
- Each derived value carries **lineage**: the list of input `SourceRef`s
  and the formula used, e.g.
  `{"op": "ltm_sum", "inputs": [refs…], "formula": "Q4'24+Q1'25+Q2'25+Q3'25"}`.

## 4. Data quality (`quality.py`)

Return a list of warnings, each with `{code, severity: info|warn|error,
kpi?, period?, segment?, message_ru, source?}`. At minimum, check for:

| code | check |
|---|---|
| `header_not_found` | configured row or column header missing |
| `formula_not_calculated` | formula cell with no cached value |
| `non_numeric_value` | unparsable text in a numeric cell |
| `segment_sum_mismatch` | Σ segments ≠ Total beyond tolerance (e.g. 0.5 unit or 0.1 %) |
| `unit_mismatch` | sheet unit label ≠ configured unit |
| `missing_period` | gap in a period series |
| `yoy_unavailable` / `ltm_incomplete` | derived metric not computable |
| `unknown_segment` | segment not in supported list |
| `stale_or_partial_read` | workbook was locked or mid-save and the last good snapshot is shown |
| `duplicate_fact` | same kpi/period/segment found twice |

Warnings are always shipped to the UI. They are never only logged.

## 5. Loader: live reload (`loader.py`)

- Poll every 2–5 s, or on each API request with a minimum interval. Read
  `stat()` first as a cheap pre-check, but **decide whether to reload by
  the SHA-256 of the file's bytes**. A changed mtime with the same hash
  means no reload. Identical mtime with different bytes (copied files,
  clock skew, tools that preserve mtime) **does** reload.
- **Ignore Excel lock and temp files**: skip `~$*` names and Excel's
  temporary save files (names starting with `~` or with no extension, and
  `*.tmp`) when discovering workbooks in `data/`.
- **Locked or mid-save tolerance:**
  1. Copy the workbook to `<project>/.cache/snapshot-<hash8>.xlsx` with
     `shutil.copyfile`, and parse the **copy**. The copy goes through a
     temp name in `.cache/` followed by an atomic `os.replace`.
  2. If the open or copy fails (`PermissionError`, sharing violation on
     Windows, `BadZipFile` or a truncated zip during save), retry with
     backoff (for example 0.2 s, 0.5 s, 1 s, 2 s; at most 5 attempts).
  3. Hash the file before and after copying. If they differ, the file
     changed mid-copy, so retry.
  4. If parsing the copy fails, keep serving the **last good snapshot**,
     add a `stale_or_partial_read` warning, and try again next poll.
  5. Clean up old snapshots in `.cache/`, keeping only the latest N.
- Swap the new model atomically, behind a lock, so a request never sees a
  half-updated model.
- Expose a `version` (the first 12 hex chars of the content hash) and a
  `loaded_at` time in `meta`. The front end polls `/api/meta` and
  re-fetches data only when `version` changes.

## 6. HTTP server (`server.py`): read-only, hardened

Use the standard library (`http.server.ThreadingHTTPServer` plus a
`BaseHTTPRequestHandler` subclass) or an equally small framework.

- **Bind `127.0.0.1` only.** Never bind `0.0.0.0` or `::`. The port comes
  from config or the CLI (default 8765).
- **Host header allow-list:** accept only `127.0.0.1:<port>` and
  `localhost:<port>`. Anything else gets `421` or `400`, which defeats DNS
  rebinding.
- **GET only** (plus `HEAD`, if you want). Every other method gets `405`
  with `Allow: GET, HEAD`. No endpoint writes anything.
- **Static files only from `web/`:** resolve the requested path, then
  require `resolved.is_relative_to(WEB_ROOT.resolve())`. Reject `..`,
  encoded traversal (`%2e%2e`, `%2f`), absolute paths, backslashes, NUL
  bytes, dotfiles and symlinks that escape. Serve only an allow-listed set
  of extensions (`.html .css .js .svg .png .woff2 .json .map`) with
  explicit `Content-Type`. Unknown paths get `404`.
- **No filesystem paths in responses:** never expose absolute paths,
  usernames or directory names in JSON, error bodies or headers. Refer to
  the workbook by basename only, and to cells as `Sheet!A1`. Error
  responses are short generic JSON (`{"error": "not_found"}`). Tracebacks
  go to the local log only.
- **Headers on every response:**
  `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`,
  `Referrer-Policy: no-referrer`, `X-Frame-Options: DENY`,
  `Cross-Origin-Resource-Policy: same-origin`, and
  `Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'self'; object-src 'none'; base-uri 'none'; frame-ancestors 'none'`.
  No CORS headers.
- Suppress the `Server` version string, and set `server_version` to a
  generic value.

### API (all GET, JSON, UTF-8)

| endpoint | returns |
|---|---|
| `/api/meta` | `{version, loaded_at, workbook: "model.xlsx", sheets, periods, years, segments, kpis:[{id,label_ru,unit}], as_of}` |
| `/api/kpis?period=2025-Q3&segment=Total&view=actual\|yoy\|ltm` | KPI values for the lens, each with `value`, `unit`, `period_label_ru`, `as_of`, `source` (sheet/cell/header) and `warning_codes` |
| `/api/series?kpi=revenue&segment=Total&view=…` | time series for charts |
| `/api/lineage?kpi=revenue&period=2025-Q3&segment=Total&view=ltm` | full lineage tree: op, formula, inputs → `SourceRef`s with raw cell text |
| `/api/warnings` | all data-quality warnings |

Validate query parameters against the known sets from `meta`. Reject
unknown values with `400`. Never echo raw input back unescaped.

## 7. Front end (`web/`)

- `index.html` holds only structure: lens controls (year/period select,
  segment select, view toggle Actual / YoY / LTM), a KPI tile grid, a chart
  area, a warnings panel and a lineage drawer. **No numbers, no embedded
  JSON, no pre-rendered figures.** Every figure comes from the API at
  runtime. Show a loading or empty state until data arrives.
- Load the chart library with `<script src="vendor/chart.umd.min.js">`
  (or whichever library you vendor). Pin the exact version and record it
  in `web/vendor/VERSIONS.txt` with its license. Never reference a CDN.
  Vendoring requires a one-off download, so do it once into `web/vendor/`
  and commit the files.
- **Formatting:** use `Intl.NumberFormat('ru-RU', …)` everywhere, which
  gives a narrow no-break space for thousands and a comma for decimals.
  Use percentages with `style:'percent'` or `п.п.` for point changes, and
  the `−` sign for negatives. Use `Intl.DateTimeFormat('ru-RU')` for dates.
  Chart axes and tooltips use the same formatters.
- **Date and unit labels:** every tile and chart shows its period label
  (for example `3 кв. 2025`, `LTM на 30.09.2025`), its unit (`млн руб.`),
  and the data `as_of` date. The header shows the workbook basename,
  `version`, and `Обновлено: <loaded_at>`.
- **Source trace:** each KPI tile has a source line
  (`P&L!F14 · «Выручка»`) and a "Источник" button that opens the lineage
  drawer, fed by `/api/lineage`. The drawer shows the derivation formula
  and the input cells with their raw values and period headers, nesting
  recursively for derived values.
- **Warnings:** a persistent, visible warnings panel with severity
  styling and a count badge in the header. Tiles affected by a warning
  show a marker, and hovering or focusing it shows the message. Show a
  `stale_or_partial_read` warning as a banner.
- **Live refresh:** poll `/api/meta` every 3–5 s. When `version` changes,
  re-fetch, re-render and keep the current lens. Pause polling while the
  tab is hidden (`visibilitychange`).
- Escape all text with `textContent`. Never set `innerHTML` with data
  from the API.
- Make it accessible: real `<select>`/`<button>` controls, focusable
  tiles, `aria-live="polite"` on the refresh status, and colour that is
  never the only signal.

## 8. Regression tests (`tests/`, pytest)

Generate fixture workbooks with a script (`tests/fixtures/make_fixtures.py`,
using openpyxl) so that the tests don't depend on a binary blob nobody can
read. Cover at least:

1. **Parser:** golden JSON snapshot of a known fixture. Running twice
   gives identical output (determinism). Periods are normalised from mixed
   header styles. Russian number text is parsed. Rows are found by header
   after a row is inserted.
2. **Metrics:** YoY including zero or missing prior, and п.п. for % KPIs.
   LTM from quarters and from YTD arithmetic. LTM is incomplete when a
   quarter is missing. Ratios aren't summed. Lineage lists the exact input
   cells.
3. **Quality:** each warning code is triggered by a dedicated fixture,
   including segment sum mismatch, uncalculated formula and unit mismatch.
4. **Loader:**
   - Same bytes with a new mtime → no reload. Different bytes with the
     same mtime (`os.utime`) → reload.
   - `~$model.xlsx` in `data/` is ignored.
   - A simulated lock or `PermissionError` on the first N attempts →
     retry, then success.
   - A truncated or corrupt workbook → the last good snapshot is kept and
     `stale_or_partial_read` is raised.
   - All temp files are created under `<project>/.cache/` and nowhere
     else.
5. **Server** (start on an ephemeral port bound to 127.0.0.1 in a fixture):
   - The socket is bound to `127.0.0.1`.
   - A bad `Host` header (`evil.com`, `127.0.0.1.nip.io`) → rejected.
   - POST/PUT/DELETE/PATCH/OPTIONS → `405`.
   - Traversal attempts (`/../dashboard/server.py`, `/%2e%2e/`,
     `/..%2fdata/model.xlsx`, `/web/../data/`) → `404` or `400`, and the
     workbook is never served.
   - No response body or header contains the project's absolute path or
     `os.sep`-joined directories (grep responses for `str(PROJECT_ROOT)`).
   - Every response has `Cache-Control: no-store` and the CSP.
   - Unknown query values → `400`.
6. **Front-end static checks:** `index.html` contains no digits-heavy
   figures or `<script>` with inline JSON, and no `http://` or `https://`
   URLs (no CDN). Every `src`/`href` resolves to a file under `web/`.
   `app.js` uses `ru-RU` formatters and doesn't use `innerHTML` with API
   data. Optionally, a Playwright smoke test (no network) checks that the
   tiles render and that the lineage drawer opens.

Run with `python -m pytest -q`. All tests must pass before you finish.
Update a golden snapshot only on purpose, and explain the diff.

## 9. Workflow when applying this skill

1. Inspect the workbook. List sheets, header rows, period headers, units
   and segments, then write `config.py`'s sheet map from what you find. Do
   not guess KPI rows.
2. Implement the parser, metrics and quality checks with their tests first
   (fixtures included).
3. Implement the loader and server with their tests.
4. Build `web/` and vendor the chart library into `web/vendor/`.
5. Run the full test suite, then start the server
   (`python -m dashboard.server --port 8765`) and check the page in a
   browser at `http://127.0.0.1:8765/`. Edit and save the workbook to
   confirm that hash-based reload works and the lens is preserved.
6. Report what was verified, any warnings the real workbook produces, and
   anything left unimplemented.

## 10. Definition of done

- [ ] Figures appear only via the API, and none are hard-coded or cached in HTML/JS.
- [ ] Every KPI tile shows its period, unit, as-of date and source cell, and has a working lineage drill-down.
- [ ] Year/period and segment lenses, plus Actual/YoY/LTM views, work. Unsupported combinations show a reason.
- [ ] Data-quality warnings are visible in the UI.
- [ ] ru-RU number and date formatting is used throughout, including on charts.
- [ ] Charts work with the network disabled, loaded from `web/vendor/`.
- [ ] Reload is triggered by content hash. `~$*` files are ignored. Locked or mid-save workbooks are tolerated.
- [ ] Server: bound to 127.0.0.1, Host allow-list, GET/HEAD only, static files only from `web/`, no paths in responses, `Cache-Control: no-store`.
- [ ] `pytest` is green. Every file written is inside the project workspace.
