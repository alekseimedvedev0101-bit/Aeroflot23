# CLAUDE.md

All work in this repository — code, skills, documentation, outputs — must follow
`PROJECT_RULES.md` in the repository root.

- Read `PROJECT_RULES.md` before starting any task.
- If a request conflicts with `PROJECT_RULES.md`, stop, point out the conflict with
  the section number, and ask the project owner (§18). Do not work around it.
- Changes listed in `PROJECT_RULES.md` §16.1 need the project owner's written approval first.
